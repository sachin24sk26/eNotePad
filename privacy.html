Help & FAQ Center
01

Information We Collect

eNotePad operates on data minimization. We only collect the minimal information necessary to sync your notes across devices:

sticky_note_2 Anonymous Shared Content

When sharing via a secret code, the note content (text, formatted link, or uploaded image/attachment) is temporarily indexed in our cloud storage so it can be retrieved on your other devices.

code Coding Room Sessions & Snippets

Code edited in Coding Room sessions is synchronized in real-time between room participants using session isolation. We do not claim ownership of, harvest, or train machine learning models on your proprietary source code.

lock Cryptographic PIN Hashes

If you choose to set a 4-digit PIN for private notes or accounts, we compute a cryptographic one-way hash. We never see or store your plaintext PIN.

person Optional Registered Account Data

If you voluntarily register an account for permanent library storage, we store your chosen username and encrypted library notes. Providing an email is completely optional.

02

How We Use Information

Data is strictly used to power real-time collaboration and platform security:

  • check_circle Instant Cross-Device Sync: Delivering notes seamlessly to anyone with your exact 6-character secret code.
  • check_circle Coding Room & Convo Rooms: Streaming keystrokes, syntax modes, live comments, and reactions exclusively between joined collaborators.
  • check_circle Abuse Prevention & Reliability: Throttling automated bots and ensuring high-availability server performance.
03

Data Security & Encryption

We employ modern industry standards to protect your shared data:

https

TLS 1.3 Transport Encryption

Every request and live sync packet is encrypted in transit over HTTPS.

security

Granular Security Rules

Database access is protected by strict Firebase Firestore security rules.

04

Auto-Deletion & Data Retention

We ensure temporary content does not linger on our infrastructure:

Content Type Retention Period Deletion Trigger
Anonymous Secret Code Notes 20 Minutes Automatic system expiry
Live Convo Rooms Duration of session + 20m idle Room exit or inactivity
Registered Account Library Indefinite (until user deletes) Manual user deletion or purge
05

Cloud Infrastructure & Third Parties

We rely on trusted cloud infrastructure to deliver lightning-fast real-time service:

• Google Cloud / Firebase: Secure database hosting, user authentication, and realtime syncing.

• Google Fonts & CDNs: Fast asset delivery for typography and icons.

06

Local Storage & Cookies

eNotePad uses your browser's local storage (LocalStorage / SessionStorage) solely to remember your preferred UI settings (like Light/Dark mode) and keep your offline active draft safe. We do not use invasive third-party cross-site cookies.

07

Your Rights & Data Control

You retain absolute sovereignty over your content:

  • delete Instant Manual Deletion: You can delete any active secret code note immediately from the app.
  • person_remove Account Purging: Registered users can permanently delete their entire account and library in 1 click under Account Settings.
