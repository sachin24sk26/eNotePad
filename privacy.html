01

Information We Collect

eNotePad operates on a privacy-first principle. We minimize the data collected to only what is strictly required to provide real-time note curation and cross-device sync.

sticky_note_2 Anonymous Notes & Shared Content

Content submitted via secret codes (text, links, images) is saved in our database to allow access across devices. No user registration is needed for anonymous sharing.

lock Secret PIN Hashes & Access Tokens

Access PINs for private notes or accounts are cryptographically hashed before storage. We never store raw PINs or plaintext access keys.

account_circle Optional Registered Accounts

If you create a personal account, we store your username, optional email address, and encrypted library preferences to allow personal file management.

02

How We Use Information

Collected data is strictly used to operate, optimize, and secure the eNotePad digital curator platform:

  • check_circle Instant Synchronization: Fetching and delivering notes using your secret code across phones, laptops, and tablets.
  • check_circle Real-Time Convo Rooms: Enabling live collaborative sessions for note curation and instant communication.
  • check_circle System Diagnostics: Monitoring server health, detecting spam or malicious abuse, and improving performance.
03

Data Security & Protection

We implement industry-grade security measures to safeguard your information against unauthorized access, disclosure, or alteration:

lock

Encrypted Transport

All connections are secured via HTTPS / TLS 1.3 protocol encryption in transit.

database

Cloud Infrastructure

Hosted on Google Cloud / Firebase Firestore with strict access control security rules.

04

Third-Party Services

We do NOT sell, trade, or monetize your personal data. We utilize trusted backend providers exclusively for app execution:

• Google Firebase: Provides authentication, real-time database storage, and file hosting.

• Google Fonts & CDNs: Delivers editorial typography and user interface assets efficiently.

05

Local Storage & Cookies

eNotePad uses Browser LocalStorage and SessionStorage to store your preferences (such as Light/Dark theme selection) and temporary secret code history locally on your device. We do not use third-party tracking cookies or advertising scripts.

06

Your Rights & Data Deletion

You retain full control over your content on eNotePad:

  • delete_forever Instant Deletion: You can delete any note, secret code content, or uploaded file at any time directly through the app interface.
  • person_remove Account Purge: Registered users can permanently delete their account and associated data from the Account settings panel.
