Frequently Asked Questions

Secret codes allow instant content sharing without needing to log in. When you save a note with a unique secret word (e.g. my-meeting-notes), anyone with that exact code can enter it on the Access panel on another device to view and retrieve the note immediately.
For security and privacy reasons, private note PINs are hashed before saving. If you set a PIN on an anonymous secret code note, it cannot be retrieved without the PIN. If you have a registered account, you can change your PIN from the Account Settings tab while logged in.
You can launch the Convo Room by clicking Convo Room in the top navigation or sidebar. You can create a new room with a room key and share the link/key with colleagues or friends to start real-time messaging and note curation together.
Yes! In the rich text editor or File Manager, you can download notes as formatted HTML, plain text (.txt), or print them to PDF directly from your browser.
eNotePad supports three main share modes:
  • Text / Rich Notes: Full rich formatting, custom fonts, lists, and highlighting.
  • Links: Instant web link sharing with auto URL formatting.
  • Images: High-resolution image uploads with preview support.
