Secret Code Not Found?

  • • Confirm the 6-character code matches exact letters.
  • • Check if the 20-minute expiry window has elapsed.
  • • Make sure you are connected to the internet.

Forgotten Note PIN?

  • • Private note PINs are hashed client-side for zero-knowledge privacy.
  • • For anonymous shares, lost PINs cannot be recovered.
  • • Registered accounts can reset PINs in Account Settings.

Convo Room Connection?

  • • Ensure both users enter the exact same room key.
  • • Convo rooms stay active during live chat and auto-clear after 20m idle.
  • • Click Re-join or refresh if disconnected.

When you click Share on eNotePad, the system generates a unique 6-character code (e.g. K9M2P4) or you can type your own memorable word. Anyone who visits eNotePad on another phone, PC, or tablet and enters that code in the Access panel instantly receives the note without signing up or logging in.

💡 Tip: Share text, formatted links, or high-res images directly without opening email or chat apps!

Auto-expiry is a core privacy feature of eNotePad. It ensures temporary passwords, one-time links, clipboard text, or sensitive snippets leave zero digital footprint on servers once retrieved.

If you want permanent storage, you can create a free account with just a username and PIN to save notes permanently in your personal Library.

When sharing a secret code note, you can optionally toggle Set Private PIN. The note is encrypted and secured with your 4-digit PIN. Anyone attempting to access the code on another device will be prompted to enter the PIN before the content is unlocked.

eNotePad features a full-featured Tactile Editorial rich text studio:

  • Typography: Switch between Editorial Serif (Newsreader), Modern Sans (Inter), and Monospace code.
  • Formatting: Bold (Ctrl+B), Italic (Ctrl+I), Underline (Ctrl+U), Blockquotes, Headings, and Checklists.
  • Exporting: Download as HTML, raw Plain Text (.txt), or Print directly to formatted PDF.

Regular note sharing is asynchronous (send a code, retrieve later). Convo Rooms are real-time, live collaborative chat rooms where multiple teammates or friends can exchange messages, images, code snippets, and live emoji reactions simultaneously.

CodeShare is a real-time collaborative code editor built into eNotePad. Anyone can start a code session, share the unique 6-character room URL with teammates or interviewers, and write code together simultaneously with syntax highlighting and zero typing delay.

Open CodeShare Editor →

CodeShare supports over 14 languages including JavaScript, Python, HTML/CSS, TypeScript, C++, Java, Rust, Go, SQL, PHP, JSON, and Markdown. It features a live in-browser Python (Skulpt) execution engine, a JavaScript runner terminal, and an instant split-screen HTML/CSS web preview runner.
